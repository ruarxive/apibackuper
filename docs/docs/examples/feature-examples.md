# Feature examples

Under `examples/features/`:

| Directory | Demonstrates |
|-----------|----------------|
| `update-resume/` | Update mode, state file, and checkpoints |
| `sqlite-storage/` | SQLite storage backend |
| `hooks/` | `before_run` / `before_request` / `after_*` scripts |
| `detect/` | `apibackuper detect --url … --write-config` |
| `concurrency-retry/` | `request.parallelism`, retries, and rate limits |
| `export-filters/` | `--fields` and `--where` on export |

Each directory includes a ready `apibackuper.yaml`.
